# ShopEase — React E-Commerce Demo

A responsive student e-commerce project built with React, Vite, React Router, CSS, and Lucide icons.

## Features
- Responsive homepage and product catalog
- Product search, category filters, and sorting
- Product detail pages
- Add/remove cart items and quantity controls
- Cart saved in browser LocalStorage
- Demo checkout form and order confirmation
- PKR currency display

## Run locally
```bash
npm install
npm run dev
```

## Build for deployment
```bash
npm run build
npm run preview
```

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Import the repository at https://vercel.com/.
3. Vercel should detect Vite automatically.
4. Use `npm run build` as the build command and `dist` as the output directory.

## Academic note
This is a frontend demo. It does not have a backend, real user accounts, inventory management, or payment processing. Product photos are loaded from Unsplash URLs and require an internet connection.
